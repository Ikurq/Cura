# Cura - 機能仕様 & セットアップ

## 🚀 セットアップ (How to Setup)

### 1. 音声モデルの取得

本アプリの音声はすべて**端末内で合成**します（VOICEVOX CORE）。APIキーもネットワークも不要です。使いたいキャラクターの音声モデルだけ、あらかじめ取得してください。

1. 設定画面 ＞ 「音声・ストレージ」を選択。
2. 使いたいキャラクターの「取得」をタップ。
3. VOICEVOX 音声モデル利用規約が表示されるので、同意するとダウンロードが始まります。
4. 取得が終わると、そのキャラクターがアラームの話者として選べるようになります。

モデルは1件あたり数十MB（最大約130MB）あります。不要になったモデルは同じ画面から削除できます。生成した音声を公開・配布する場合は、各キャラクターのクレジット表記（例:「VOICEVOX:ずんだもん」）が必要です。

### 2. 権限の設定

カレンダー同期や確実なアラーム動作のために、以下の設定を推奨します。

* **カレンダー権限**: 設定 ＞ 「権限設定」から許可することで、時間割の自動同期が可能になります。
* **バッテリー最適化の解除**: アラームがバックグラウンドで確実に鳴動するために必要です。

## 🛠 主な機能

### 1. VOICEVOX アラーム

* **音声合成**: VOICEVOX CORE による端末内での音声合成。任意のテキストをアラーム音声にできます（オフライン動作）。
* **高度な通知設定**:
    * 曜日指定の繰り返し設定。
    * アラーム時のバイブレーション有効/無効切り替え。
    * アラーム鳴動時に「当日のタスク」を併せて読み上げる機能。
* **音声キャッシュ**: 一度生成した音声はローカルに保存（.wav）し、再生成の待ち時間を削減。

### 2. スケジュール・カレンダー同期

* **外部同期**: Android標準カレンダーの読み込み、および外部iCal (.ics) 形式のURLからの予定インポート。
* **プリセット**: 定期的な講義情報をテンプレートとして保存し、一括登録。
* **カレンダー選択**: デバイス内の複数のカレンダーから、同期対象を個別に選択可能。

### 3. タスク管理

* **タスクリスト**: 期限付きミッションの管理。
* **一括処理**: 複数タスクの同時完了処理。
* **アラーム連携**: 前述の通り、アラーム音声の末尾にタスク情報を動的に追加。

### 4. キャラクターシステム (Cura)

ホーム画面に常駐し、マスターの単位管理をサポートするAIパートナーです。

* **キャラクター設定**:
    * **名称**: Cura（キュラ / CU-RA v2.0）
    * **定義**: Curation & Rehabilitation Assistant。語源はラテン語で「世話」「癒やし」。
    * **性格**: 献身的なお節介焼き。マスターの怠惰には少し厳しい。
    * **特性**: 低電力（15%以下）や未完了のタスクを嫌い、状態がログに反映される。
* **システム連携**:
    * **成長システム**: タスク完了などで経験値が溜まり、レベルアップ。
    * **衣装の自動切替**: レベルや季節、時間帯に応じてコスチュームが変化。
    * **インタラクション**: タップでの反応や、下部「SYS_LOG」での状況報告・独り言。

### 5. システム設定・管理

* **HUDカスタマイズ**: ユーザー名の変更、レベル表示のON/OFF切り替え。
* **ストレージ管理**: 音声モデルの個別削除と、生成された音声キャッシュの一括削除。

### 6. 出欠管理システム (Attendance Management) ※追加機能

* **統計トラッキング**: 講義ごとの出席・欠席・遅刻回数をカウント。
* **自動連携**: スケジュールから出席すべきコマを自動抽出。

## ⚙️ 技術仕様

* **言語**: Kotlin
* **アーキテクチャ**: Fragmentベースの構成 (Single Activity)
* **データ保持**: SharedPreferences (JSON構造化保存)
* **音声合成**: VOICEVOX CORE (端末内合成 / [vv-mobile](https://github.com/Shakenokirimi12/vv-mobile) 経由)
* **主な使用ライブラリ**: Material Components, Lottie, Glide, Coroutine
* **対応環境**: Android 8.0 (API 26) 以上 / arm64-v8a・x86_64
