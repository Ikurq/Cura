# Cura - 機能仕様 & セットアップ (v2.0)

## 🚀 セットアップ (How to Setup)

### 1. 音声エンジンの組み込み
本アプリは **VOICEVOX ローカルエンジン** を搭載しており、オフラインで音声合成が可能です。

*   **動作環境**: Android 8.0 以上
*   **初期化**: アプリの初回起動時に、音声合成に必要な辞書データ等のセットアップが自動的に行われます。
*   **オフライン動作**: 外部APIを使用しないため、通信環境がない場所でもアラーム音声の生成が可能です。

### 2. 権限の設定
カレンダー同期や確実なアラーム動作のために、以下の設定を推奨します。
*   **カレンダー権限**: 設定 ＞ 「権限設定」から許可することで、予定の自動同期が可能になります。
*   **バッテリー最適化の解除**: アラームがバックグラウンドで確実に鳴動するために必要です。

## 🛠 主な機能

### 1. VOICEVOX ローカルアラーム
*   **多彩な声で起床**: 内蔵されたVOICEVOXエンジンにより、お好みのキャラクターの声で目覚めることができます。
*   **予定連動アラーム**: カレンダーの予定から逆算して、最適な時間にアラームを自動生成します。
*   **鳴動救済ロジック (v2.0)**: 万が一アラーム停止画面を見失っても、アプリを開き直すだけで確実に停止画面へ誘導します。

### 2. スケジュール・カレンダー同期
*   **外部同期**: Android標準カレンダー、および外部iCal (.ics) 形式のURLからの予定インポートに対応。
*   **出欠管理**: 授業や会議などの予定に対する、出席・欠席・遅刻の回数を自動で集計し統計を記録します。

### 3. タスク管理
*   **優先度設定**: ミッションの重要度に応じた整理が可能です。
*   **経験値還元**: タスクを完了することでCuraの成長（EXP）に反映されます。

### 4. キャラクターシステム (Cura)
ホーム画面に常駐し、マスターの生活をサポートするAIパートナーです。

*   **インタラクション (v2.0 強化)**:
    *   **呼吸の演出**: ゆったりとした微かな動きにより、静止画ではない「生きている気配」を感じさせます。
    *   **充電反応**: 電源の接続・切断に対し、リアルタイムで反応します。
    *   **衣装切替**: レベルや季節、時間帯に応じてコスチュームが変化します。
*   **システムHUD (v2.0 刷新)**:
    *   画面上部にCuraの内部思考やシステムログを表示。更新時にはデジタルノイズ（グリッチ）が走ります。

### 5. 報酬・成長体験 (v2.0 新機能)
*   **ご褒美ストック (Pending EXP)**: 他の画面で得た経験値を溜めておき、ホーム画面に戻った瞬間にまとめて受け取る演出を追加。
*   **ハイテク・ゲージ**: 複雑なメカを思わせる新しいゲージデザインと、滑らかな上昇アニメーションを実装。

## 🎨 UI/UX のこだわり (v2.0)
*   **リキッド・インターフェース**: メニュー選択時に背景が生き物のように盛り上がる、一体感のあるアニメーション。
*   **没入型デザイン**: スマホ最上部のステータスバー色をアプリ背景と完全に一致させ、画面全体を一つの専用端末のように演出。

## ⚙️ 技術仕様
*   **言語**: Kotlin
*   **音声エンジン**: [vv-mobile](https://github.com/Shakenokirimi12/vv-mobile) (VOICEVOX Android)
*   **主な使用ライブラリ**:
    *   Material Components (Material 3)
    *   Lottie / ValueAnimator (アニメーション)
    *   Glide (画像処理)
    *   Coroutine (非同期処理)
