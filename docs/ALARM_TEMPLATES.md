# アラーム音声テンプレート仕様書 (ALARM_TEMPLATES.md)

予定連動アラームおよび起床後モーニングリーディングの音声セリフは、以下のJSONファイルで一括管理されています。

- **ファイル配置場所**: `app/src/main/assets/alarm_templates.json`
- **内部ストレージ上書き場所 (任意)**: `custom_alarm_templates.json` (アプリ内ストレージに配置された場合、こちらが最優先されます)

---

## 1. 予定連動アラーム (mandatory_alarm) の拡張方法

### 構造
`mandatory_alarm` の下に `categories` が定義されています。  
各カテゴリーには「表示名 (`name`)」と「テンプレート一覧 (`templates`)」の配列を記述します。

```json
"mandatory_alarm": {
  "categories": {
    "standard": {
      "name": "標準",
      "templates": [
        "%d時%d分を過ぎています。%sまであと%d分です。起きてください。",
        "{time}です。{event}まであと{leadTime}分となりました。起きてくださいね。"
      ]
    },
    "urgent": {
      "name": "焦り・緊急",
      "templates": [
        "起きて！もう%d時%d分！%sまであと%d分しかないよ！急いで！",
        "緊急事態！{time}だよ！{event}まであと{leadTime}分しかない！早く飛び起きて！"
      ]
    },
    "gentle": {
      "name": "優しめ",
      "templates": [
        "朝ですよ。%d時%d分になりました。%sまであと%d分あるから、ゆっくり準備してね。"
      ]
    },
    "custom_category": {
      "name": "新しい方向性名",
      "templates": [
        "ここにお好みのセリフを追加"
      ]
    }
  }
}
```

### 使用可能なプレースホルダー（埋め込み変数）
波括弧 `{...}` 形式を使うと、変数の順番を自由に入れ替えたり、不要な変数を省略したりできます。

| 変数名 | 説明 | 例 |
|---|---|---|
| `{time}` | アラーム鳴動時刻 (何時何分) | `7時30分` |
| `{hour}` | 時 (数値) | `7` |
| `{minute}` | 分 (数値) | `30` |
| `{event}` または `{summary}` | 連動する予定のタイトル | `ゼミ発表` |
| `{leadTime}` | 予定開始までの残り分数 | `30` |

※従来の `%d` (時) / `%d` (分) / `%s` (予定名) / `%d` (残り分) による位置指定書式もそのまま利用可能です。

### 新しい「方向性（トーン）」の追加
`categories` の中に新しいキー（例: `"tsundere"` や `"robot"`）を追加するだけで、アプリ側のアラーム生成画面のスピナーに自動的に選択肢として表示されます。
生成時に「おまかせ (全方向性からランダム)」を選択した場合は、全カテゴリーの全テンプレートから毎回ランダムに選ばれます。

## 2. 起床後モーニングリーディング (morning_reading) の拡張方法

アラーム停止後に再生されるスケジュール・タスク読み上げの各パーツも、文字列だけでなく**文字列の配列（リスト）**で記述できます。  
配列で指定すると、毎朝その中からランダムに1文が選ばれます。

```json
"morning_reading": {
  "greeting": [
    "おはようございます。ただいま、%sです。",
    "朝の予定確認です。現在は%sになります。",
    "おはようございます！時刻は%sです。今日のスケジュールをお伝えします。"
  ],
  "event_relative_before": [
    "「%s」まで、あと%d分です。",
    "まもなく「%s」が始まります。あと%d分です。"
  ],
  "event_relative_after": [
    "「%s」の開始時刻から、%d分過ぎています！急いでください！",
    "大変です！「%s」の開始から%d分経過しています！"
  ],
  "event_relative_just": [
    "「%s」の開始時刻ちょうどです。",
    "ただいま「%s」の開始時刻です。"
  ],
  "event_list_header": "今日の予定は、",
  "event_item": "%sから%s、",
  "event_list_footer": "です。",
  "task_list_header": "今日のタスクは、",
  "task_item": "%s、",
  "task_list_footer": "があります。",
  "closing": [
    "今日も一日、元気に頑張りましょう！",
    "いってらっしゃい！充実した一日を過ごしてくださいね。",
    "今日もマイペースに、無理せず頑張っていきましょう。"
  ]
}
```
